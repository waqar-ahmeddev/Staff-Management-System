# 🧑‍💼 Staff Management System

A **full-stack Staff Management System** built with the **MERN Stack** to help companies manage staff, attendance, leaves, customers, and employee records from a centralized dashboard.

## 🚀 Tech Stack

* **Frontend:** React.js, Redux Toolkit, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **UI:** Shadcn UI

## ✨ Features

* 🔐 JWT Authentication
* 👨‍💼 Admin & Staff Roles
* 👥 Staff Management
* 🕒 Check-in / Check-out
* 📊 Daily & Monthly Attendance
* 📝 Leave Management
* 👤 Staff Profiles
* 🧑‍🤝‍🧑 Customer Management
* 🛡️ Role-Based Access Control

## 🎯 Project Goal

This project is designed as a real-world **internal company management system**, demonstrating full-stack development, REST APIs, authentication, authorization, database management, and frontend state management using modern technologies.
